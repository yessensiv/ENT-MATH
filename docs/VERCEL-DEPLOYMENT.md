# Vercel production

Публичный сайт: https://ent-math.vercel.app. Дополнительные адреса Vercel могут требовать входа в Vercel; ученикам нужен основной домен.

Сборка: npm ci, затем npm run build:vercel. Подключены Turso и Google OAuth. Сервер проверяет сессию Google. Настройки и миграция описаны в VERCEL-DATABASE-AUTH.md.

Первый вход открывает форму учебного профиля. Исходный сайт Cloudflare и история сохранены. История ChatGPT ещё не перенесена в Google-аккаунты: требуется актуальный экспорт и подтверждённая привязка пользователей.

Проверены production-сборка, публичный доступ, реальный Google-вход, отказ API без авторизации, запись/чтение с откатом в Turso и изолированные проверки сохранения. Полный учебный сценарий на двух устройствах пока не подтверждён.

ИИ на Vercel требует отдельных серверных настроек провайдера; локальные ключи не копировались. Независимые автоматические резервные копии отложены владельцем. Ключи и архивы исключены из Git и загрузки.
