# ENT Math

Работающая образовательная платформа подготовки к ЕНТ: русский и казахский интерфейс, 82 урока, 1230 проверенных задач, три направления, диагностика, личный маршрут, практика, тетрадь ошибок, повторения, экзамены и редактор.

## Открыть

https://ent-math-learning.netabasyn.chatgpt.site

Первоначальная публикация приватная, доступна владельцу. Вход через ChatGPT, затем создание учебного профиля. Локальный вход использует явно обозначенный тестовый аккаунт Sites; его записи не переносятся в опубликованную базу. Для других учеников владелец отдельно изменяет аудиторию сайта в Sites. Самостоятельные email/пароль и школьный SSO не подключены.

## Локальный запуск

Node.js 22.13+ (проверено на 24.19) и npm. Из каталога проекта:

```powershell
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 migrations apply DB --local --config dist/server/wrangler.json --persist-to .wrangler/state
npm run dev
```

Откройте http://127.0.0.1:5173. Сборка перед первым запуском создаёт конфигурацию D1; миграции создают таблицы. `.wrangler/state` содержит локальные результаты. Применённые миграции в `drizzle/` не изменяйте; изменения схемы оформляйте новой миграцией.

Если запуск npm в Windows выдаёт ошибку пути, используйте установленный CLI напрямую:

```powershell
node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' run dev
```

Опубликованный сервер работает в Cloudflare Workers, данные — в D1. Sites создаёт привязку `DB` и применяет миграции при публикации. Ответы проверяются сервером. Урок восстанавливается по теме и этапу; экзамен — по серверному времени, ответам и отметкам.

## Подключить генеративного наставника и редактора

Без внешнего ключа доступен обозначенный «Учебный помощник»: подсказки, проверка доказуемых ошибок в шагах и решения из материалов. Он не выдаётся за генеративную модель.

1. Получите ключ провайдера с OpenAI-совместимым `POST /chat/completions`. Для получения ключа OpenAI через Codex подключите плагин OpenAI Developers и следуйте его процессу выдачи ключа.
2. Локально скопируйте имена из `.env.example` в игнорируемый `.dev.vars` в корне проекта. Задайте `TUTOR_API_KEY`, `TUTOR_BASE_URL` (например, `https://api.openai.com/v1`), `TUTOR_MODEL` и `TUTOR_DAILY_LIMIT=30`; перезапустите сервер.
3. Для облака задайте те же переменные через управление окружением Sites (`sites_update_environment_variables`) для проекта из `.openai/hosting.json`. `TUTOR_API_KEY` помечается секретом. Локальный файл не настраивает опубликованный сервер.
4. Задайте `ADMIN_EMAILS` — адреса аккаунтов ChatGPT редакторов через запятую. По умолчанию редакторов нет. Только для локальной проверки можно указать `seedy@sites.test`.
5. После изменения облачного окружения повторно разверните сохранённую версию. После входа редактора появляется «Панель редактора»; после подключения ключа — «ИИ подключён».

Ключ не передаётся браузеру. По умолчанию 30 запросов на ученика в сутки (настраивается 1–200), до 700 выходных токенов на ответ, тайм-аут 16 секунд. При сбое уроки и обычные подсказки остаются доступны. Стоимость и общий денежный потолок настраиваются у провайдера: приложение ограничивает запросы, а не платежи.

## Проверки

```powershell
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/engine.test.ts tests/bank.test.ts
node --test tests/http-readonly.test.mjs
node --test tests/http-preferences.test.mjs
node --experimental-strip-types --test tests/http-learning.test.mjs
npm run build
```

HTTP-проверки требуют работающего локального сервера. `http-learning` сохраняет тестовые записи; повторный запуск требует новых задач. Повтор уже решённой задачи не повышает освоение. Всего прошли 49 проверок: 23 движка и банка, 7 защиты API, 15 полного процесса, 4 дополнительных возможностей. Подробнее в STATUS.md.

## Редактирование

Контент — `lib/content.ts`; проверка, маршрут, повторение и экзамены — `lib/engine.ts`; хранение и редактор — `lib/server-store.ts`; интерфейс — `components/learning-app.tsx`; модели — `components/math-visuals.tsx`.

Редактор принимает полные двуязычные материалы в JSON, сохраняет статусы «Черновик», «На проверке», «Опубликовано» и историю. Публикация требует комментария проверки и серверной валидации. Новые произвольные задания ИИ автоматически не публикуются. Алгоритм официального оценивания изменяется через проверку исходного кода и новую версию; черновик правил не меняет баллы.
