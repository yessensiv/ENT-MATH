# Vercel preview

Отдельная сборка: `npm run build:vercel`. Основная сборка Cloudflare и её хранилище не меняются.

Vercel использует Next.js и отдельный адаптер окружения без имитации Cloudflare D1. На сайте есть предупреждение о предварительном статусе. Программа и уроки доступны; аккаунты, серверное сохранение истории и ИИ не подключены. Недоверенные заголовки `oai-authenticated-user-*` не дают доступ к аккаунтам в Vercel.

Для полного переноса необходимы: постоянное хранилище с проверяемой миграцией Cloudflare D1; авторизация (Google OAuth с client ID, secret и callback нового домена); серверные переменные провайдера ИИ; резервное копирование и проверка восстановления. Ключи вводятся в Environment Variables Vercel, не в репозиторий. `.dev.vars`, локальная база, архивы и ключи исключены из загрузки.

Проверка: Next.js production build завершён; локально главная страница 200 и предупреждение предварительной версии присутствует. Дальнейшие проверки записываются после публикации.
