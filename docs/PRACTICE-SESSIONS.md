# Практика: сессии, закрепление и обратная связь

Состояние: локальная версия, проверена 07.10.2026. Изменения этого этапа ещё не опубликованы на production.

## Что реализовано

- Сохранённая сессия с фиксированным составом. Для следующей новой сессии можно выбрать 10, 15 или 20 задач. При недостатке подходящего банка показывается фактическое количество, без выдуманных заданий. Уже начатая сессия не меняется при расширении банка.
- Подбор сложности учитывает текущие самостоятельные подтверждения и необходимость восстановления: начинающему больше базовых задач. Причина подбора доступна в самой практике.
- Номера задач со статусами, переходы назад/вперёд, восстановление ответов и шагов. Адрес `#practice/<session-id>`. Возврат к проверенной задаче открывает сохранённую первую попытку, не начисляя опыт заново.
- Серверная проверка, оптимистическая блокировка версии сессии и повторяемые запросы с идентификатором. Конфликт двух устройств не перезаписывает ответ молча. Незаконченные соответствия и выражения сохраняются как черновики.
- Неотправленные изменения дополнительно сохраняются на устройстве, отдельно для аккаунта, сессии и задачи. После ошибки связи автоматические повторные отправки останавливаются; доступна явная повторная отправка.
- После ошибки — сохранённый разбор и до двух новых проверенных упражнений на тот же метод. Дополнительные упражнения не увеличивают основной счётчик. Два новых самостоятельных правильных ответа закрывают назначенную ошибку, но не подменяют её исходный результат и не подтверждают отложенное освоение.
- Можно продолжить основную практику без закрепления. Цепочка ошибок не порождает бесконечную очередь: исходная ошибка получает два упражнения, ручная вариация ограничена четырьмя дополнительными условиями суммарно.
- Для новых шаблонов отложенное повторение сохраняет конкретный метод и выдаёт новое условие. Другая задача той же темы не засчитывается вместо назначенного метода; повторение до срока не подтверждает освоение. Последующие интервалы сохраняют эту привязку.
- Чат привязан к аккаунту, сессии и конкретному заданию. После завершения он исчезает из активной практики, оставаясь доступным для чтения в отчёте. Общий наставник отделён от контекста задачи. Новые сообщения в завершённую сессию отклоняются.
- Явное завершение с количеством непроверенных вопросов, сохранённый отчёт, архив прошлых практик. Самостоятельные ответы, помощь/знакомые условия, первоначальные ошибки, пропуски и закрепление показаны раздельно.
- Обратная связь и разрез по проверяемым навыкам. План пересчитывается штатным учебным алгоритмом; отчёт показывает назначенное повторение и переход к следующему действию. В кабинете можно продолжить незавершённую сессию.
- Читаемые варианты вместо «A — A», безопасное отображение формул, крупные кнопки на телефоне. Сообщение редактору доступно и в новом тренажёре.

## Генерация и её реальные границы

Добавлены 21 семейство вычислительных шаблонов в семи темах: числа, дроби, проценты, степени, линейные уравнения, квадратные уравнения, выборка и вариационный ряд. Это прямые, обратные, составные задачи, ситуации с бюджетом, тарифами, водой, ценами, геометрией и выборками.

Каждое новое условие строится из ограниченных параметров. Перед включением проверяются каноническое условие, оба языка, ответ, решение, единицы, тип, навык и математическое соотношение. Второй вычислительный контроль подставляет ответ в исходное соотношение. Уровни сложности являются авторской классификацией и требуют калибровки преподавателем.

Кнопка «Новое условие · ИИ + проверка» доступна после ответа на задачу нового шаблона. ИИ выбирает числовой параметр; условие и ключ строит код. Произвольные сгенерированные тексты и ответы ИИ не поступают в основной банк. Используется тот же серверный провайдер и дневные ограничения, что у наставника. При отказе, лимите или некорректном ответе провайдера работает вычислительный шаблон, а интерфейс честно сообщает, что ИИ не использовался.

Точная связь старых задач с закреплением есть для 36 методов в 12 темах, плюс для новых шаблонов. Для остальных старых задач без подтверждённой связи ошибка не закрывается случайным упражнением: доступны разбор, урок и продолжение. Расширение таких связей по всей школьной/экзаменационной программе остаётся отдельной предметной работой.

Новые материалы имеют статус `computed-template;human-review-pending`. Проверки кода не являются независимой проверкой преподавателя, методиста или казахского редактора. СОР/СОЧ не добавлены.

## Запуск

Из каталога проекта в PowerShell:

```powershell
npm.cmd run dev -- --port 5174
```

Локальный адрес: `http://127.0.0.1:5174/#practice`. Одна копия dev-сервера на проект; уже работающий процесс повторно запускать не нужно.

Настройки наставника читаются на сервере из `.dev.vars`: `TUTOR_PROVIDER`, `TUTOR_BASE_URL`, `TUTOR_MODEL`, `TUTOR_API_KEY`. Ключ не должен попадать в исходники, браузер или отчёт. Для новых условий отдельного ключа не требуется. Без ключа учебная практика и проверяемое закрепление работают; свободные ответы наставника требуют провайдера.

## Данные, резервирование и откат

SQL-схема не менялась. Добавлены поля состояния `practiceSessions` и `activePracticeId`. Старые попытки, ошибки, прогресс, экзамены и чаты не удаляются. Приватные снимки заданий в сессиях исключены из общего `/api/state`; ответы выдаются после проверки соответствующей задачи. Серверные ограничения экзамена/диагностики сохраняются.

Перед изменениями выполнен согласованный SQLite backup через SQLite backup API: `.sites-runtime/backups/practice-sessions-2026-10-06/`. Исходники точек интеграции сохранены рядом. HTTP-тест дополнительно резервирует и восстанавливает голову состояния, части, события и резервные копии локального тестового аккаунта, с контролем версии.

Откат интерфейса: вернуть предыдущую версию кода; добавленные поля можно оставить в состоянии, поскольку они не заменяют прежние данные. Восстановление всей SQLite-копии выполнять только при остановленном сервере и после отдельного экспорта более новых данных: иначе будут потеряны результаты, полученные после даты копии. Автоматическое внешнее резервирование production отложено по решению владельца.

## Проверки

- TypeScript без ошибок; production-сборка проходит.
- 199 модульных/компонентных проверок — весь набор файлов `*.test.ts` и не-HTTP `*.test.mjs`: прежняя учебная логика, новые сессии, более 12 тысяч комбинаций шаблонов, сохранение частичных ответов, повторные запросы, отсутствие ключей в выдаче, отказ/некорректный ответ ИИ, подбор сложности и повторение конкретного метода.
- Отдельный HTTP-сценарий: старт → черновик → другая вкладка → конфликт → ошибка → два закрепления → исходная задача → завершение → сохранённый отчёт → новая сессия. Данные тестового аккаунта восстановлены после проверки.
- Браузер: возврат между вопросами; конфликт и восстановление; ошибка/закрепление; реальный запрос к подключённому ИИ с новым проверенным условием; независимая проверка ответа; завершение; русский/казахский; ширина 390 px без горизонтального переполнения, навигационные кнопки высотой 46 px.
- Новый модуль практики и его API проходят ESLint. Общий старый `learning-app.tsx` имеет ранее накопленные замечания React Hooks; весь репозиторий нельзя объявить прошедшим полный lint.

Артефакты проверок: `.sites-runtime/tests/practice-regressions.txt`, `practice-build.txt`, `practice-lint.json`, `practice-report-desktop.png`, `practice-report-mobile.png`. Скриншоты отчёта содержат явно обозначенные тестовые данные.
