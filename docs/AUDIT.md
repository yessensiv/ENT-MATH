# ENT Math: аудит и исправления, 6 октября 2026

Проверена работающая платформа, а не только внешний вид. Для найденных дефектов сначала воспроизведён сценарий, затем внесено исправление и добавлена проверка там, где она проверяет существенное поведение. Абсолютное отсутствие ошибок при любых будущих данных не заявляется.

| Сценарий | Исправление |
|---|---|
| Ученик снова ошибается в освоенной теме | Освоение открывается для повторного подтверждения; нужны три новых самостоятельных решения и проверка спустя время |
| Повторное подтверждение освоения | Первоначальная награда не начисляется повторно |
| Много одинаковых ошибок | Исправление серии даёт одну награду после нескольких новых решений, а не награду за каждую копию ошибки |
| Ответ уже раскрыт в экзамене или диагностике | Такая задача не считается новой для освоения и отложенного повторения |
| Закончились первоначальные новые задачи | Выдаётся проверенный вариант из конечного резерва; исчерпание резерва явно сообщается |
| Условие задания изменилось без изменения ключа | Проверка исходных условий и параметров отклоняет несогласованный вариант |
| Неверная привязка вводной темы функций к НЦТ | Вводные функции и преобразования отмечены как подготовка и исключены из экзаменационной квоты |
| Неполный или посторонний ответ экзамена | Проверяется допустимый формат и принадлежность вариантов конкретному вопросу |
| Экзамен истёк, повторный запрос завершения | Сервер закрывает экзамен по дедлайну и возвращает уже сохранённый результат без повторного начисления |
| Медленное соединение, ответ изменён во время сохранения | Последняя версия отправляется после предыдущей; более старый запрос не заменяет новый ответ |
| Быстрый уход или перезагрузка | Сохраняются черновик ответа, шаги, диагностика, экзамен и текущая позиция |
| Поздний ответ на задачу после перехода к другой | Прогресс сохраняется для исходной задачи; её обратная связь не показывается у новой |
| Старая загрузка кабинета или материала | Проверяется актуальность версии состояния и контекста страницы |
| Сбой связи | Загруженный кабинет остаётся на экране; ошибка и повтор соединения показаны явно |
| Цель при переходе между направлениями | Целевой результат хранится отдельно для каждого направления |
| Сокращение дроби с потерей области определения | Проверяются дополнительные критические точки знаменателей; недопустимый тангенс отклоняется |
| Маленький экран и управление визуалами | Читаемые подписи SVG, крупная область касания, клавиатура, сохранение параметров вкладок |
| Изменение знаменателя модели дробей | Если доля не выражается целым числом плиток, округление явно объясняется |
| Длинная история занятий | Хранение разбивается на части; обновление защищено от одновременных записей |
| Раннее повторение после ошибки | Оно закрепляет навык, но не заменяет проверку минимум через сутки после третьего нового самостоятельного решения |
| Позднее сохранение черновика после отправки ответа | Отметка завершения не позволяет старому запросу восстановить уже завершённую задачу; новый черновик сохраняется |
| Кабинет без активного экзамена | Отметки обрабатываются без обращения к отсутствующему экзамену |
| Пространственная модель | Исправлена интерполяция вертикальных координат граней; все точки SVG числовые |
| Повторное открытие редактора | Загружаются сохранённый черновик, ответ, переводы, статус и история |
| Повторная сборка перед миграцией | Отдельная конфигурация локальной базы сохраняет путь к миграциям |

82 урока содержат собственный порядок решения, объяснение обозначений и условий, примеры, памятки и реальный вопрос понимания. Основной банк: 1230 задач. Дополнительный резерв: 20 342 проверенных варианта новых условий. Это авторские тренировочные задания, не официальные задания ЕНТ.

Финальный прогон: **122 успешные проверки** — 79 движка, контента, хранения, визуалов и жизненного цикла интерфейса; 24 проверки API ученика; 15 полного учебного пути; 4 проверки редактора. TypeScript, ESLint и производственная сборка прошли без ошибок. Предупреждений ESLint нет: списки зависимостей эффектов проверены отдельно, намеренные зависимости по идентификаторам документированы; сценарии поздних ответов выполняют реальные функции интерфейса.

Полный путь повторно проверен на изолированном локальном профиле: диагностика, ошибка, контекстная помощь, новые самостоятельные решения, полный экзамен 50/50, выход и повторный вход. Исходные местные результаты восстановлены с проверкой ревизии. В браузере проверены сохранение и восстановление редакторского черновика, русская и казахская практика и отсутствие переполнения на ширине 320/390 px. Временная локальная роль редактора удалена.

Хранилище принимает до 32 частей по 180 000 UTF-16 символов. Проверен реальный D1-снимок более 2 МБ с кириллицей, казахским текстом и emoji, контроль целостности, одновременные записи и откат при ошибке. Лимит не скрывается: превышение возвращает ошибку до обновления и оставляет прежнее сохранение.

Остаются необходимыми ключ генеративного ИИ, независимая методическая и казахская редактура, калибровка сложности на учениках, школьные нагрузочные испытания и резервное копирование. Подробный статус и воспроизводимые команды проверки — в [STATUS.md](STATUS.md) и [README.md](../README.md).
