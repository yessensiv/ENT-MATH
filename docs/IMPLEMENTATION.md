# ENT Math — план реализации

Дата: 5 октября 2026. Программа: ЕНТ 2026.

## Учебная архитектура

Три независимых направления: основы → профильная математика → математическая грамотность. Результаты и диагностика хранятся по направлению. Полная карта находится в CURRICULUM.md. Каждый узел — конкретный навык с предпосылками, уроком на 10–15 минут, тремя примерами и банком задач трёх уровней.

Урок: цель → объяснение и термины → формула с ограничениями → три примера → совместное решение → самостоятельная практика → проверка → памятка. Освоение требует самостоятельных ответов и успешного отложенного повторения.

## Порядок разработки

1. Сверка официальной программы, карта навыков и структура контента.
2. Постоянное хранилище, аккаунт, разграничение доступа.
3. Первый учебный путь: профиль → диагностика → маршрут → урок → задача → ошибка → контекстная помощь → новая задача → сохранение.
4. Расширение банка, русский и казахский языки.
5. Повторение, тетрадь ошибок, аналитика и достижения.
6. Пять вариантов экзамена, таймер, четыре формата, оценивание, разбор.
7. Управляемые визуализации и панель редактора.
8. Проверка браузером на компьютере и телефоне, проверка API, сборка и публикация.

## Дизайн

Основной экран — учебный кабинет. Постоянное левое меню, сверху название направления, по центру один главный следующий шаг, справа календарь и наставник. Фон #F6F8FA, белые поверхности, тёмный текст #172D2A, зелёный #19775C, мятный #E9F5EF, лавандовый #EEEAF8 и жёлтый #F9E6A0. Типографика: Manrope с кириллицей и системным запасным шрифтом. Крупные заголовки, короткие строки, ясная иерархия. Математический мотив — координатная сетка с кривой на главной карточке и маленький персонаж с карандашом. Мобильное меню открывается кнопкой; поля и кнопки не менее 44 px. Анимации только для обратной связи, учитывают reduced-motion.

Рекомендация UI/UX поиска с детскими шрифтами и claymorphism отклонена: аудитория 9–11 классов. Приняты доступность, размер целей, фокус клавиатуры и адаптивность.

## Данные и честность

Аккаунты и прогресс сохраняются на сервере в D1. В публикации используется вход ChatGPT; локальная тестовая идентичность явно обозначена. Демонстрационный просмотр отделён от личных данных. ИИ работает через сервер; при отсутствии ключа доступен обозначенный учебный помощник на проверенном контенте. Для полной генеративной модели требуется настройка секрета.

Материалы, созданные автоматически, проходят вычислительные проверки; полноценная независимая методическая и языковая редактура отмечается отдельно. Официальный источник, дата и версия правил доступны ученику.
