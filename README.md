# ENT Math — школа 5–11 и ЕНТ

Образовательная платформа подготовки к ЕНТ, выпуск 06.10.2026: русский и казахский интерфейс, 121 урок, 1 815 статических задач и 21 494 проверенных дополнительных условия (20 342 для ЕНТ/основ и 1 152 школьных). Три направления, диагностика, личный маршрут, практика, тетрадь ошибок, повторения, экзамены и редактор. Дополнительный пул конечный; вычислительная проверка не заменяет преподавательскую редактуру.

## Открыть

[ENT Math](https://ent-math-learning.netabasyn.chatgpt.site)

Сайт опубликован с публичной аудиторией; это подтверждено настройками Sites. Для сохранения личных результатов нужен вход через ChatGPT, затем создание учебного профиля. Настоящий облачный вход владельца и сохранение после повторного входа ещё нужно проверить. Локальный вход использует явно обозначенный тестовый аккаунт Sites; его записи не переносятся в опубликованную базу. Самостоятельные email/пароль и школьный SSO не подключены.

## Локальный запуск

Node.js 22.13+ и npm. Из каталога проекта:

```powershell
npm ci
npm run db:migrate
npm run dev
```

Откройте http://127.0.0.1:5173. Миграции используют сохранённый в проекте `wrangler.local.json`, поэтому предварительная сборка не нужна. `.wrangler/state` содержит локальные результаты. Применённые миграции в `drizzle/` не изменяйте; изменения схемы оформляйте новой миграцией. Для проверки производственной сборки отдельно выполните `npm run build`.

Если запуск npm в Windows выдаёт ошибку пути, используйте установленный CLI напрямую:

```powershell
node 'C:\Program Files\nodejs\node_modules\npm\bin\npm-cli.js' run dev
```

Опубликованный сервер работает в Cloudflare Workers, данные — в D1. Sites создаёт привязку `DB` и применяет миграции при публикации. Ответы и самостоятельность решения проверяются сервером. Восстанавливаются тема и этап урока, черновик ответа и шагов практики, незавершённая диагностика, ответы, отметки и позиция экзамена. Экзамен использует серверное время.

Большая история сохраняется фрагментами с контрольной суммой и проверкой версии при одновременных изменениях (CAS). Лимит — до 32 фрагментов по 180 000 единиц UTF-16, примерно 5,76 млн единиц UTF-16 для всего состояния ученика, включая историю и сохранённые задачи. Хранение не безлимитное. При превышении ёмкости сервер возвращает понятную ошибку; история не должна молча обрезаться.

## Подключить генеративного наставника и редактора

Без внешнего ключа доступен обозначенный «Учебный помощник»: подсказки, проверка доказуемых ошибок в шагах и решения из материалов. Он не выдаётся за генеративную модель.

1. Получите ключ провайдера с OpenAI-совместимым `POST /chat/completions`. Для получения ключа OpenAI через Codex подключите плагин OpenAI Developers и следуйте его процессу выдачи ключа.
2. Локально скопируйте имена из `.env.example` в игнорируемый `.dev.vars` в корне проекта. Задайте `TUTOR_API_KEY`, `TUTOR_BASE_URL` (например, `https://api.openai.com/v1`), `TUTOR_MODEL`, `TUTOR_VISION_MODEL` (модель с поддержкой изображений), `TUTOR_DAILY_LIMIT=30` и `TUTOR_DAILY_TOKEN_LIMIT=120000`; перезапустите сервер.
3. Для облака задайте те же переменные через управление окружением Sites (`sites_update_environment_variables`) для проекта из `.openai/hosting.json`. `TUTOR_API_KEY` помечается секретом. Локальный файл не настраивает опубликованный сервер.
4. Для этого опубликованного проекта `ADMIN_EMAILS` владельца уже настроен через серверное окружение Sites. Для добавления редакторов укажите адреса их аккаунтов ChatGPT через запятую. Для локальной проверки отдельно можно задать `ADMIN_EMAILS=seedy@sites.test` в `.dev.vars`; локальная настройка не меняет облачные роли.
5. После изменения облачного окружения повторно разверните сохранённую версию. После входа редактора появляется «Панель редактора»; после подключения ключа — «ИИ подключён». Настройка адреса не подтверждает успешный облачный вход: этот сценарий ещё предстоит проверить.

Ключ не передаётся браузеру. По умолчанию 30 запросов на ученика в сутки (настраивается 1–200), до 700 выходных токенов на ответ, тайм-аут 16 секунд. При сбое уроки и обычные подсказки остаются доступны. Стоимость и общий денежный потолок настраиваются у провайдера: приложение ограничивает запросы и резервирует бюджет токенов, а не платежи. Фото до 2 МБ (PNG/JPEG/WebP) отправляется выбранному провайдеру только для распознавания; изображение не сохраняется. Ученику нужно проверить распознанные знаки и подтвердить текст перед отправкой наставнику. Без ключа распознавание закрыто, ручной ввод и учебный помощник доступны.

## Школьная математика 5–11 классов

Раздел «Школа · 5–11 классы» содержит отдельные упорядоченные маршруты каждого класса. В 7–11 классах темы разделены на алгебру/анализ и геометрию. Выберите класс и нажмите «Назначить личный план»: профиль, диагностика, план первой недели и аналитика будут учитывать выбранный класс. Общие уроки используют те же навыки и сохранённый прогресс, что подготовка к ЕНТ. Для школьного профиля дата и балльная цель ЕНТ при регистрации не запрашиваются.

На платформе 39 отдельных школьных уроков / 585 задач: 8 исходных и 31 добавленный в этом обновлении. Всего с ЕНТ — 121 урок / 1 815 статических задач. Для восьми исходных школьных тем доступны 1 152 дополнительных проверенных условия; для 31 нового урока пока по 15 статических задач. В 10–11 классах ЕМН/ОГН выбираются отдельно. Четверти — рекомендуемый порядок платформы, который нужно сверить с планом учителя.

Покрытие всех государственных учебных целей и глубина пока частичные. Точные оставшиеся материалы и источники перечислены в [школьной карте](docs/SCHOOL-CURRICULUM.md). Независимая методическая и казахская редактура ещё нужна. СОР и СОЧ не включены.

## Учитель, родитель, занятия без интернета

В разделе «Учитель и родитель» взрослый создаёт одноразовый код (24 часа). Ученик проверяет имя и роль и отдельно подтверждает передачу имени, класса и агрегированной статистики. Родитель видит отчёты; учитель также назначает практику с количеством новых задач и сроком. Чат, email, фотографии и ответы не передаются. Доступ можно отозвать; сервер проверяет его для каждого запроса. До согласия отчётов нет.

В «Без интернета и копии» скачайте HTML-урок. В файле работают теория, примеры, формы ответов, шаги, локальное сохранение и выгрузка JSON. При возвращении в сеть загрузите JSON на сайт: сервер проверит ответы и сохранит ошибки. Можно сначала загрузить часть, затем оставшиеся; повторная загрузка не дублирует попытки. Файл содержит решения, поэтому эти задачи считаются практикой с доступной помощью; освоение подтверждается отдельными новыми задачами онлайн. Доступны последние 10 скачанных уроков. Это автономные файлы, а не весь сайт без сети и не офлайн-экзамены.

Предыдущий прогресс автоматически копируется при первом изменении каждого дня. Копии доступны 7 дней; можно вручную создать текущую. Восстановление требует выбора и подтверждения, проверяет версию сохранения и сначала делает копию текущих данных. Снимки и части находятся в той же D1: защита от ошибочного изменения есть, независимый аварийный архив ещё нужно настроить.

Программа НЦТ 2026 повторно сверена 06.10.2026. Профиль: 40 заданий, типы 25+5+5+5, уровни 20/12/8, максимум 50 баллов. Грамотность: 10 заданий, уровни 5/3/2, максимум 10. По пять различных вариантов. Оценивание версионировано по пункту 18 Правил ЕНТ. 80/20 минут на отдельный предмет — собственная настройка тренировки. Другой год требует новой сверки.

Целевые результаты хранятся отдельно по направлениям. Освоение требует трёх новых самостоятельных правильных решений и успешного повторения минимум через сутки после третьего. Задачи, уже показанные в диагностике или экзамене, просмотренные подсказки, разобранные примеры и контрольный вопрос урока не считаются свежим самостоятельным подтверждением. Новая ошибка снимает подтверждённое освоение и назначает восстановление; награда 50 XP за освоение одной темы выдаётся только один раз. Игровой уровень показывается отдельно от математического освоения.

При исчерпании статических новых заданий практика и повторение используют проверенный детерминированный пул. Он содержит новые числовые условия авторских шаблонов, а не бесконечные задачи ИИ. После исчерпания соответствующего пула нужны новые редакторские материалы; точные границы приведены в [карте программы](docs/CURRICULUM.md).

## Проверки

```powershell
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test "tests/*.test.ts" tests/math-visuals.test.mjs tests/ui-lifecycle.test.mjs
node --experimental-strip-types --test --test-concurrency=1 tests/http-readonly.test.mjs tests/http-preferences.test.mjs tests/http-reliability.test.mjs tests/http-storage-generation.test.mjs tests/http-draft-order.test.mjs
node --experimental-strip-types tests/run-learning-flow.mjs
node --experimental-strip-types tests/run-school-flow.mjs
node --experimental-strip-types tests/run-support-offline-flow.mjs
node --experimental-strip-types --test tests/http-school-expansion.test.mjs
npm run build
```

HTTP-проверки запускайте только против работающего локального сервера на 127.0.0.1:5173. Они используют общий обозначенный тестовый аккаунт и поэтому выполняются последовательно (`--test-concurrency=1`); не направляйте `ENT_TEST_BASE_URL` на опубликованный сайт. В набор входят `http-reliability.test.mjs` и `http-storage-generation.test.mjs` — черновики, одновременное сохранение, большой снимок истории и новые варианты. `http-learning.test.mjs` сохраняет реальные записи локального тестового аккаунта, включая попытки и экзамены; повторный запуск может потребовать новых задач. Не используйте этот аккаунт вручную во время HTTP-прогона.

Пройдены 164 проверки текущего выпуска, TypeScript, ESLint и производственная сборка. Полный учебный путь повторно проверен с изоляцией и восстановлением местных данных. Подробности — [docs/AUDIT.md](docs/AUDIT.md).

Для HTTP-проверок сначала создайте учебный профиль в локальном тестовом аккаунте и оставьте браузер вне занятия. `run-learning-flow.mjs` выполняет полный процесс с отдельным временным состоянием и восстанавливает исходные результаты. Четыре проверки редактора запускаются отдельно: временно задайте `ADMIN_EMAILS=seedy@sites.test` в `.dev.vars`, перезапустите сервер, через редактор сохраните черновик задачи `linear-3` и выполните `node --experimental-strip-types --test tests/http-admin.test.mjs tests/http-editorial.test.mjs`. Затем удалите только эту временную настройку и перезапустите сервер с обычной ролью; проверки ученика требуют отсутствия роли администратора.

## Редактирование

Контент — `lib/content.ts`; проверка, маршрут, повторение и экзамены — `lib/engine.ts`; хранение и редактор — `lib/server-store.ts`; интерфейс — `components/learning-app.tsx`; модели — `components/math-visuals.tsx`.

Редактор предлагает обычные поля RU/KK для названия, теории, формул, условия, решения, подсказок и ключа; остальные данные сохраняются. Расширенные данные доступны отдельно. Загрузка полного задания с ключом через `/api/admin?kind=task&id=...` защищена ролью редактора. Статусы «Черновик», «На проверке», «Опубликовано», комментарии и история сохраняются. Публикация исправленного материала требует серверной валидации и трёх сохранённых заключений для точной версии: математика, методика и казахский язык. Изменение текста отменяет их применимость; произвольный редакторский текст требует согласованного ключа и человеческой проверки. Новые произвольные задания ИИ автоматически не публикуются. Алгоритм официального оценивания изменяется через проверку исходного кода и новую версию; черновик правил не меняет баллы.

Остаются: подключение внешнего ИИ и проверка распознавания настоящих фото, независимая редактура, калибровка сложности, перечисленные дополнения школьной карты, проверка облачного входа на разных устройствах, испытание школьной нагрузки и независимый аварийный архив D1. Проверка выражений покрывает используемые шаблоны и не является универсальной системой символьной математики; свободные доказательства и физические построения автоматически не оцениваются. Точный перечень — в [STATUS.md](docs/STATUS.md).
