# Практика по всем темам — 9 октября 2026

В действующий банк добавлены 2 607 авторских заданий ENT Math: 1 815 основных
и 792 отдельных упражнения закрепления. Охвачены все 121 тема: школьная
программа 5–11 классов, базовая и профильная математика, математическая грамотность.
По каждой теме доступны пять новых условий каждого из трёх уровней. Для каждого
метода и формата основного набора остаются минимум два новых условия закрепления.

Это расширение авторского банка. Оно не означает перенос всех упражнений
учебников. Число готовых адаптаций из источников остаётся 1 821 в 32 темах.
Рекомендованная литература в отчёте является ориентиром по теме, а не
приписанной авторским заданиям ссылкой на исходное упражнение. Материалы с
ограничением коммерческого использования здесь не копируются.

## Работа платформы

- Новый банк включён в `baseContent`; незавершённая практика продолжает использовать
  сохранённые снимки прежних задач.
- Задания закрепления не попадают в основную практику. После ошибки подбираются
  два невиденных условия того же метода, уровня и формата, вне текущего основного набора.
- Только два правильных самостоятельных ответа закрывают соответствующую ошибку.
  Результаты закрепления учитываются отдельно в отчёте.
- У каждого задания есть RU/KK условие, минимум три подсказки и три шага решения.
  Ключи и решения не передаются до проверки или обращения за помощью.
- Авторство и статус вычислительной проверки отображаются в интерфейсе.
  Независимая проверка методики, переводов, сложности и соответствия возрасту остаётся необходимой.
- Ошибки и прогресс сохраняются действующими механизмами платформы. Миграция базы не требуется.
- Новые задания не подменяют диагностику, экзамены и разобранные примеры уроков.
- Генерация выполняется при подготовке банка, без платных запросов к ИИ.

## Проверка и запуск

Пересоздать банк: `npm run practice:build`. Команда сначала проверяет новые условия,
потом записывает JSON и отчёт. При недостатке уникальных условий или корректных
упражнений закрепления подготовка завершается ошибкой.

Проверить все условия и сценарий каждой темы: `npm run practice:verify`.
Дополнительно выполняются общие тесты проекта, проверка TypeScript и сборка.
Сквозная проверка API: `tests/http-curriculum-practice.test.mjs` на порту 5188,
только с отдельной локальной базой. Этот тест создаёт собственный учебный аккаунт.

Запуск для ученика: `npm run dev -- --port 5174`, затем открыть
`http://127.0.0.1:5174`. Для получения нового набора завершить текущую практику
и начать новую. Переключение языка не сбрасывает ответы.

Отчёт: `docs/CURRICULUM-PRACTICE-COVERAGE.html`; данные:
`docs/CURRICULUM-PRACTICE-COVERAGE.json`.

## Откат

Исключить `curriculumPracticeTasks` из списка в `baseContent`, чтобы остановить
выдачу новых заданий. Сохранённые сессии и история содержат снимки условий;
их нельзя удалять. Обработчик проверки ответов и поддержку авторских упражнений
закрепления оставить для уже назначенных задач. Первоначальные ID и содержимое
уроков, диагностики и экзаменов не меняются.
