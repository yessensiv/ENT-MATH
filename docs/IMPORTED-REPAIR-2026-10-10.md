# Закрепление импортированных заданий

Добавлена резервная генерация новых авторских условий для 1 585 заданий автоматического импорта, описанных в `content/promoted/verification.json`. Она применяется после исчерпания подходящих заданий банка. Основные задания и сохранённые попытки не меняются.

Сохраняются тема, семейство метода, уровень, формат ответа. Числовые варианты допускаются только при точном рациональном результате; квадратные корни проверяются на полный квадрат. Уравнения и неравенства преобразуются заменой переменной, с переносом корней, границ и ограничений. НОД и НОК пересчитываются. Неподдерживаемый вариант отбрасывается.

Новые условия помечаются авторскими, без ложной ссылки на номер упражнения учебника. Независимая проверка переводов остаётся ожидающей. Закрепление состоит из двух отдельных упражнений и не увеличивает основной счётчик практики. Повторные запросы используют уже назначенный резерв.

Проверено: весь основной набор 236 тестов; отдельно четыре теста расширения, включая математическую проверку переноса корней и неравенств, исчерпание исходного банка для каждого из 1 585 шаблонов, знаки корней, ошибку → два закрепления → восстановление состояния → исправленную ошибку. Проверка TypeScript и ESLint изменённых модулей прошла.

Сборка запущена, но зависла на первом этапе анализа компонентов; успешная сборка не подтверждена. Новый HTTP/браузерный прогон этой версии не выполнен. Это расширение не заявляет генерацию для старого ручного импорта без структурированных математических доказательств: там по-прежнему используются подходящие проверенные упражнения банка.
